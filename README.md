# Machine Learning-Based Financial Fraud Detection

## Project Overview
This project explores financial transaction fraud detection using machine learning techniques, including Isolation Forest and supervised learning models.

## Objectives
- Detect potentially fraudulent transactions.
- Address the challenges of highly imbalanced transaction data.
- Compare supervised learning and anomaly detection approaches.
- Evaluate models using precision, recall, F1-score, and ROC-AUC.

## Technologies Used
- Python
- Pandas and NumPy
- Matplotlib and Seaborn
- Scikit-learn
- Google Colab
- GitHub

## Dataset
The project uses a PaySim-style financial transaction dataset.

Note: The dataset is not included in this repository. Refer to the original dataset source for access.

## Project Workflow
1. Data preprocessing
2. Exploratory data analysis
3. Feature engineering
4. Model training
5. Performance evaluation
6. Model comparison

## How to Run
1. Open the notebook in Google Colab.
2. Obtain access to the dataset.
3. Update the dataset path in the notebook.
4. Run the cells sequentially.
